# Insurance-Analysis Using SQL & Power BI

## Project Overview

Tracks sales performance across Cross Sell, New, and Renewal categories.
Key metrics: CSIA%, CSPA%, NIA%, NPA%, RIA%, RPA%.
Visuals show target vs achieved vs invoiced revenue, sales funnel, meetings per executive, invoice counts, and top 5 opportunities.
Provides insights into performance, pipeline, and opportunity management.

## 🛠 Process Overview

🔷 SQL Process Overview
Extract data from systems (e.g., Invoices, Opportunities, Meetings).

Use SQL to clean, join, and calculate metrics (e.g., targets, achievements).

Create views/tables with KPIs and load into Power BI.

🟣 Power BI Process Overview
Import SQL data and define relationships.

Create DAX measures for KPIs (e.g., CSIA%, NPA%).

Build visuals: bar charts, pie charts, funnel, cards.

Use slicers/filters for interactivity.

Arrange in a dashboard layout for insights.
